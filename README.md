# Lotus Fragrance

Landing e-commerce dimostrativa per Lotus Fragrance, con modalità chiara/scura, carrello locale, codice demo `LOTUS10`, informativa cookie e sezione dashboard illustrativa.

## Prima della vendita reale

- Configurare Stripe e i metodi alternativi con un backend sicuro; non inserire chiavi segrete nel repository.
- Sostituire metriche, prodotti, prezzi e informazioni societarie di esempio con dati reali.
- Far validare privacy, cookie, termini, resi, fiscalità e consegne da un professionista qualificato nelle giurisdizioni di vendita.

L'app è predisposta per Fly.io nella regione di Milano (`mxp`).
